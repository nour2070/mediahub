# Documentation de l'API MediaHub

## 1. Lister toutes les publications
- **Méthode** : GET
- **URL** : `/api/publications`
- **Réponse** : JSON contenant la liste des publications.

## 2. Afficher une publication spécifique
- **Méthode** : GET
- **URL** : `/api/publications/{id}`
- **Réponse** : JSON contenant les détails de la publication.
